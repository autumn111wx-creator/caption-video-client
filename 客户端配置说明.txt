黑底字幕视频工具 3.0 试用版

一、启动与退出
1. 双击“黑底字幕视频工具.exe”启动，目录里只保留这一个启动入口。
2. 软件启动后，Windows 右下角托盘会显示蓝色播放图标。
3. 可直接关闭主窗口，或点击窗口底部“退出软件”，也可右键托盘图标选择“退出软件”。三种方式都会结束后台进程。

二、背景视频
1. 不选择背景视频：自动生成纯黑背景视频。
2. 选择背景视频：使用所选视频作为画面；画面过短会自动循环，过长会按配音时长裁切。
3. 新视频使用本次生成的配音，原视频声音不会保留。
4. 可导入 MP4、MOV、MKV、WebM、AVI、WMV、M4V、FLV。

三、文字和字幕
1. 支持 TXT、SRT，也可直接粘贴文字。
2. 导入 SRT 时会提取字幕正文，再按本次配音重新生成时间轴；不会沿用原 SRT 的时间码。
3. 字幕显示原文；“发音词典.tsv”只改变朗读方式，不改变屏幕文字。

四、输出格式
视频：MP4、MOV、MKV、WebM、AVI。
音频：WAV、MP3、M4A、FLAC、OGG。
文字：SRT。

五、音色与倍速
1. 倍速范围 0.5–2.0，步长 0.1。
2. 把 JSON 音色配置放到“音色配置”目录，重启软件后自动识别。
3. JSON 示例：
   {
     "name": "云扬 · 男声",
     "voice": "zh-CN-YunyangNeural"
   }
4. 音色配置是 Edge TTS 的音色名称，不是 WAV/MP3 录音文件。

六、网络和成品
自然语音由 Edge TTS 在线生成，需要联网，输入的文字会发送到语音服务。
视频转换在本机完成。成品保存在软件目录旁的“成品”文件夹。
